# sqlit

[English version](./README.md)

A user friendly TUI for SQL databases. Written in python. Supports SQL server, Mysql, PostreSQL, SQLite, Turso and more.

![sqlit](https://repo.x-cmd.io/sqlit.svg?lang=zh)

## 安装

```sh
x install sqlit
```
